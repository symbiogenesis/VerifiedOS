# Bounded typed storage entries

The numeric `VOSNODE1` codec is a bring-up index instance. It cannot encode
[the L2 tuple](../proofs/KeyspaceDomains.v#K2) or an authenticated extent in one
64-bit value. The bounded typed codec uses the tuple's actual
[lexicographic order](../proofs/KeyspaceDomains.v#ksig): domain, namespace,
kind, object, attribute, version. Snapshot selection first selects a retained
root; version order within that root does not require scanning every snapshot.

For this C instance each component is an unsigned 64-bit integer. Its key is
exactly six big-endian words, so unsigned byte comparison preserves the tuple
order without truncation, hashing or an indirection. The general Gallina naturals
need an explicit fitting proof before conversion into this bounded instance.

`VOSEXT01` is a 96-byte extent descriptor: magic (8 bytes), physical block
address, byte length, nonce node identity and generation (four little-endian
64-bit words), domain epoch and kind (two little-endian 32-bit words), the full
16-byte AES-GCM tag, then the independent 32-byte keyed content digest. Nonce
coordinates must fit the existing canonical node-nonce codec. Address and length
must additionally fit the selected medium and extent at integration; this codec
does not authorize IO, authenticate a tag or establish content freshness.

A typed leaf entry occupies the key and whole descriptor inline. Its admission
computes capacity from the selected block/header sizes and refuses a block that
cannot hold one entry. The numeric 128-byte node instance therefore cannot be
silently reused for typed leaves. Typed update/publication, production composition,
C/Gallina refinement and target execution remain M5.3d/M5.4 joins.

## Typed node and routing contract

The next executable M5.3d boundary stores the complete key and extent inline in
typed leaves. `VOSTYP01` nodes use the numeric codec's 32-byte header layout:
magic, little-endian 32-bit kind and count, then little-endian 64-bit node
identity and generation. A leaf stores `count` consecutive 144-byte entries
(48-byte key followed by its complete 96-byte extent); a branch stores
`count - 1` complete keys followed by `count` little-endian 64-bit child
identities. Padding is canonical zero. The selected geometry must fit a full
leaf at its declared fanout, between two and sixteen. Numeric node bytes and
the undersized numeric block geometry refuse rather than convert implicitly.

Input and output objects must be disjoint and remain stable for each call.
Encoding and decoding validate local shape, identity, generation, references,
extent coordinates and padding before changing caller output. They preserve
all six key components and every authentication byte. They do not authenticate
blocks, establish physical extent bounds or select a production geometry.

Full-tree lookup admits strict lexicographic leaf/separator order, inherited
half-open key ranges, exact declared leaf depth and finite depth/visit bounds
over stable caller-authenticated blocks and independently bound generations.
It returns an extent only after every reachable branch is admitted. Path lookup
checks the same conditions on the selected root-to-leaf path; an unvisited
subtree is not admitted by that operation. A true miss and structural refusal
are distinct and both preserve output. Expected generations come from independent
retained-root evidence, never the untrusted block's own identity fields. Repeated
references to an empty subtree are permitted when each inherited interval admits
it, following [the reference's well-formed predicate](../proofs/ExecutableIndex.v#well_formed);
each reference consumes a visit. This interface adds no unique-parent condition.
A cyclic reference cannot outlive the
declared finite depth. Empty leaves and single-child branches retain the
reference's admitted local shapes.

Acceptance requires independently generated canonical bytes and tuple-order
expectations across every key component and full-width boundaries, exact extent
metadata on found results, retained-root/generation controls and positive misses.
Malformed ordering, ranges, references, depth, padding, generations and work
limits refuse without output changes. Compiled routing and admission defects
must compile, execute and fail their specified assertions. Focused native C
checks supply this bounded codec/read evidence; typed CoW updates, authenticated
publication, C/Gallina refinement and purecap target execution remain open. This
bounded extension is not the production codec: its Narcissus grammar/canonicity,
branch authentication metadata and parametric correspondence remain governed by
[the production typed-key contract](tree-image.md#production-typed-keys-and-authenticated-values).

The codec passes when independent generated byte vectors round-trip complete
full-width tuples and descriptors; byte comparison agrees with tuple order,
including namespace/kind and 64-bit boundaries; malformed lengths, magic and
nonce coordinates refuse without output changes; and fitted geometry includes
every inline metadata byte. Native regression and executed malformed inputs are
focused checks, with hosted acceptance retained by the shared handoff.
