# Bounded typed storage entries

The numeric `VOSNODE1` codec is a bring-up index instance. It cannot encode
[the L2 tuple](../proofs/KeyspaceDomains.v#K2) or an authenticated extent in one
64-bit value. The bounded typed codec uses the tuple's actual
[lexicographic order](../proofs/KeyspaceDomains.v#ksig): domain, namespace,
kind, object, attribute, version. Snapshot selection first selects a retained
root; version order within that root does not require scanning every snapshot.

For this C instance each component is an unsigned 64-bit integer. Its key is
exactly six big-endian words, so unsigned byte comparison preserves the tuple
order without truncation, hashing or an indirection. The general Gallina naturals
need an explicit fitting proof before conversion into this bounded instance.

`VOSEXT01` is a 96-byte extent descriptor: magic (8 bytes), physical block
address, byte length, nonce node identity and generation (four little-endian
64-bit words), domain epoch and kind (two little-endian 32-bit words), the full
16-byte AES-GCM tag, then the independent 32-byte keyed content digest. Nonce
coordinates must fit the existing canonical node-nonce codec. Address and length
must additionally fit the selected medium and extent at integration; this codec
does not authorize IO, authenticate a tag or establish content freshness.

A typed leaf entry occupies the key and whole descriptor inline. Its admission
computes capacity from the selected block/header sizes and refuses a block that
cannot hold one entry. The numeric 128-byte node instance therefore cannot be
silently reused for typed leaves. Typed node routing, production composition,
C/Gallina refinement and target execution remain M5.3d/M5.4 joins.

The codec passes when independent generated byte vectors round-trip complete
full-width tuples and descriptors; byte comparison agrees with tuple order,
including namespace/kind and 64-bit boundaries; malformed lengths, magic and
nonce coordinates refuse without output changes; and fitted geometry includes
every inline metadata byte. Native regression and executed malformed inputs are
focused checks, with hosted acceptance retained by the shared handoff.
