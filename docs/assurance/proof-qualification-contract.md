# Proof qualification acceptance contract

This contract precedes the Q19a/Q19b experiments and M6.2b-i bounded checker qualification. The locked proof environment is `verifiedos-rocq-9.2.0-ocaml-5.4.1`; compatibility experiments must use their own native lane and disposable or separate switches. The integrator owns the final full repository proof/host gates. Local trials compile and audit only their exact sources and dependencies, recording this narrower scope.

## Q19a and Q19b

The baseline is `proofs/CopyRingService.v` and its imported RingContract. Diagnostic trials must exercise a real broken publish/take bound, an unfinished proof, and restoration of exact original bytes. A retained launcher binds diagnostics to source, imports, configuration and tool identity, marks provisional results, and refuses stale cached presentation. A selected editor server and rendered backend are qualified separately, including actual protocol/diagnostic attempts and measured setup/replay/repair latency. HTML, caches and interactive recovery never override batch compilation, assumption audit or kernel recheck.

Library experiments preserve the named helper/client statements and exact assumption closures: `andb_split`, `andb_join`, the `nat_leb_*` helpers, `publish_keeps_the_invariant`, `take_keeps_the_invariant`, and `the_invariant_survives_every_interleaving`. Compare the retained handwritten positive with a selective Stdlib/replayable candidate, including a representative client edit. Report setup, repair and replay separately. A dependent-definition candidate must reduce concrete examples and expose its equation behavior without silently adding global UIP or an undeclared assumption. Explicitly rejecting a failed or unjustified candidate is a valid trial outcome. Final CopyRing bytes and the installed proof-switch package/export identity must equal baseline.

## M6.2b-i

Select one immutable checker/dependency tuple, read its own licenses, and name its real source constants. Inventory all explicit normalization, flags, universe, typing-environment, guard and implementation premises. Source reachability is not a transitive compiled assumption audit. Qualification may reject a source that lacks a required proof, parser, compatible constant or bounded interface; every missing input must be named at its existing owner with a scoped estimate rather than absorbed into this trial.

A positive result requires accepted/refused serialized proofs over the selected subset, a bounded wire grammar and canonical decoding, a fixed bump arena reset after each term, and a precise source-to-CompCert-C refinement endpoint over that decoder, checker state/result and resource behavior. Installed packages or a paper are insufficient. This contract authorizes inspection and bounded compatibility probes, not vendoring a checker, inventing a normalization theorem, enlarging R-05-163's admitted set or implementing M6.2b-ii.

The final trial documents carry results, exact commands, immutable evidence identity, costs, residue and retention/rejection. Third-party integration, checklist/log state and shared generated artifacts remain integrator-owned.
