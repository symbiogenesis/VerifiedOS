[default status observation](default-status-observation.json) record actual argv,
operation timestamps, verdicts, current validation times and distinct historical
compilation timing. They measure these checks alone, not implementation time or

[index](index.json) are exact byte copies of their native metadata files. Default

[configuration](configuration.json) retain the exact operation inputs. Future
invocations may materialize them into unique OS Temp, use the observation's other
inputs and revalidate through the private driver. The controller index remains a
lookup hint: these public metadata copies cannot replace native compiler,
source, object, tool or installed-library inputs.

restore the unchanged controller receipt and index at the exact absolute paths
recorded by `capture.json`'s `native_retention`; do not rebase either file. Preserve

here.
