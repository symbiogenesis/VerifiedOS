# Locked Rocq native module census

This original producer reads Rocq 9.3.0's installed native module/declaration API.
The [support census contract](../../docs/implementation/contracts/sail-support-census.md)
owns its acceptance boundary. The [inventory note](../../docs/implementation/q35q-native-inventory.md)
records executed evidence and remaining obligations.

The default mode preserves `verifiedos-rocq-native-metadata/1`: constructor-based
types, universes and names with explicitly unqualified implementation connections.
It supplies no declaration census. `--census` selects the separate
`verifiedos-sail-support-census/1` [schema](census-schema.json) and
[wire contract](SCHEMA.md). Neither helper mode alone qualifies Q35q's hosted exact
assumption and recursive-kernel joins.

Run a focused native census using an existing locked switch, immutable precompiled
support and its complete precompiled stdpp/bitvector mapping:

```sh
python3 tools/run.py rocq-census \
  --switch-root /root/.opam/verifiedos-rocq-9.3.0-ocaml-5.4.1 \
  --out /root/build/lane-ASSIGNED/native-census-NEW \
  --support-source /absolute/retained/support/src-stdpp \
  --stdpp-source /absolute/retained/stdpp \
  --census --search \
  --targets CensusControls,SailStdpp.TypeCasts,SailStdpp.State_monad
```

The `rocq-census` dispatcher runs [qualify.py](qualify.py). The helper copies the
supplied objects into its fresh output directory and compiles only the original
[plugin](vos_rocq_census.ml) and Gallina controls. It installs nothing and never
compiles installed or supplied dependency sources. Every subprocess has an
absolute temporary working directory. System environment variables are inherited;
tool/plugin discovery and target/request selection are explicit additions.

`--targets` names the exact loaded roots. In census mode, `--search` retains each
root's native Search query and raw streams, then derives the complete ordered
resolution requests through [census.py](census.py). Alternatively, `--requests`
accepts an explicit ordered request array. The helper binds a private request file
by its absolute path, exact bytes and hash before and after the native query.
`--component-receipt` binds an exact selected-support component build. These inputs
do not replace hosted cold-source acceptance.

The census exports complete field classifications, abstract interface obligations,
native original/instantiated implementation metadata, nested module descents and
ordered native substitutions. Alias evidence retains exported and canonical names;
the adapter passes only independently proven owned canonical declarations to the
unchanged common inventory guard. Concrete aliases and abbreviations require their
own explicit assumption-audit bindings. Module-type and unapplied-functor fields
remain obligations and never become global assumption queries.

Types use versioned native constructors, including relevance, casts, case and
recursion metadata, projections, universe instances, abstract universe contexts
and declaration contexts. Module expressions, typing flags, inductive metadata,
global universe/quality graphs and finite-domain native resolver effects retain
their stated coverage. Transparent bodies are hashed from the complete constructor
encoding in memory and discarded; only their identities and complete reference
domains are emitted. No executable library body AST, debugging term printer or
marshalled runtime object supplies acceptance. Unsupported constructors, concrete
abstract implementations, rewrite rules, unresolved references and implementation
refinements refuse.

`receipt.json` persists invocation intent before every native launch and records
source, launcher, compiler, request and input identities. It rescans `.vo`/`.glob`
membership and bytes beneath the installed library and supplied inputs; installed
native APIs/link inputs, source inputs and the actual copied/loaded plugin,
controls and dependency objects are also protected. Added, deleted or changed paths
refuse the evidence verdict. These are observations at the recorded cuts, not a
claim about every machine file or the interval between cuts.

Strict compiler diagnostics remain refusals. Exhaustive native constructor matches
compile with missing-case warnings as errors. The helper requires exactly one
well-formed emission of the selected schema with the exact requested roots.
Timeouts, launch/copy/read/log failures, stderr diagnostics, changed requests and
identity drift refuse; raw native exit codes remain separate from the final
evidence verdict. Focused helper tests exercise interruption and copied-input
mutation paths. Python fixtures qualify no native behavior.

The standalone [hosted route](../ci/sail_support_route.py) cold-builds all selected
support modules, retains recursive native module readings, replays the adapter,
audits exact owned and alias assumptions, runs native positive/refusal controls and
the recursive kernel checks, then verifies unchanged identities. Only its replayed
`native-census-qualified.json` can complete Q35q. Later snapshot export/import is
Q35n's separate decision. The [bounded owner acts](../../docs/implementation/contracts/sail-support-census.md#census-continuation)
retain every candidate counter and refusal; the original
[metadata checkpoint](checkpoint.json) remains metadata-only.

The original sources use Apache-2.0. Installed Rocq/Stdlib implementations are not
copied here; compiled plugins and support objects stay in native storage. The
[licensing inventory](../../THIRD-PARTY.md) records the inspected dependency terms
and the distributed type/provenance evidence boundary.
